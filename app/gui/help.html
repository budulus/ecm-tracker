1The workflow

ECM Tracker follows a simple five-step pipeline. Work through it top to bottom — the toolbar is grouped in the same order.

  1. Load an image sequence (a folder or a set of files).
  2. Define a region of interest (ROI) on your reference frame.
  3. Seed feature points inside the ROI — automatic corners or a regular grid.
  4. Track the points across the frame range, forward and backward.
  5. Clean up low-quality tracks, then export the survivors.

2Loading images

From the File menu (or the toolbar):

  • Open Directory… (Ctrl+O) — load every image in a folder, in name order.
  • Open Files… — pick an explicit set of images.
  • Open Image Pair… — choose a reference image and a destination image, then align them before tracking.

Images of any common format are accepted and normalised internally, so colour and grayscale sources mix freely.

Two-frame tracking

In the alignment window, the reference stays fixed while you drag the destination over it. Adjust Destination opacity to compare features. Use the X/Y offsets or arrow keys for one-pixel adjustments; hold Shift with an arrow key for ten pixels. Positive X moves right, and positive Y moves down. Scroll to zoom, and use Space+drag or right-drag to pan.

Choose Translation, Uniform Scale, or Affine. Scale handles preserve aspect ratio; affine handles adjust stretch and shear while preserving parallel edges. By default, corner handles keep the opposite corner fixed and the scale percentage scales about the center, preserving existing affine proportions. Each mode remembers its settings.

To keep an aligned feature fixed while scaling, translate it into place first, click Set Pivot, then click that feature on the destination image. A yellow marker shows the pivot. Both the scale percentage and corner handles keep it fixed, including affine adjustments and switching deformation modes. Zoom and pan remain available while picking; Escape cancels picking. Translation and rotation carry the pivot with the feature. Clear Pivot restores default scaling without moving the image. The pivot is remembered when reopening alignment and saving or loading a pair setup; choosing or clearing it alone preserves tracking.

Enable Rotation in any mode, then use the angle field or orange round handle. Rotation is clockwise about the destination center. Turning it off remembers the angle for later. Reset Alignment clears all offsets, rotation, deformation presets, and the pivot.

The green boundary is the largest fully valid rectangular overlap. Apply Alignment crops both images to this area. Integer translations use exact pixel crops; other transforms resample the original destination once. Different dimensions, scales, and orientations are allowed. Originals stay unchanged. Continue with the usual ROI, detection, tracking, and cleanup tools.

Coordinates: tracking measures the remaining motion after the manual alignment is removed. Coordinates in tracking and coordinate exports start at the cropped image's upper-left corner. Add the saved crop origin to recover original reference coordinates; for original destination coordinates, apply the inverse saved alignment to those reference-space coordinates (subtracting the shift alone works only for translation).

In the Affine Zone Tool, Include alignment affine maps if present is enabled by default. It restores alignment scale/shear in the table, plots, CSV, and direction gauge, while excluding alignment translation and rigid rotation. Disable it to inspect residual deformation. Reported directions use restored, rotation-aligned axes; gauge arrows are mapped back onto the aligned image. Other analysis plugins continue to analyze residual motion.

Use File → Save Pair Setup… to save the source-image references and alignment in an .ecmpair.json file, even before defining points. Reopen it with Open Pair Setup…; keep the original images available. Relative image paths allow moving a setup and its images together. Save tracking separately with Save Trackers…, then restore it with Load Trackers… after reopening the same pair setup.

Parameters → Adjust Pair Alignment… reopens the original images for adjustment. Cancelling or applying unchanged geometry preserves your work. Applying changed geometry asks before clearing the ROI, points, tracking, and cleanup history. Save the updated pair setup afterwards.

3Choosing frames

Three sliders at the bottom of the window control which frames you see and track:

  • Reference — the start of the tracked range. Your ROI and feature points are defined here.
  • Last — the end of the tracked range.
  • Current — the frame currently shown on the canvas (move it freely to inspect any frame).
Note: changing the Reference frame or the ROI invalidates an existing tracking result, so you'll be asked to confirm before it is discarded.

4Defining a region (ROI)

The ROI bounds where features are seeded. Use the Define button's dropdown to pick a shape:

  • Rectangle — click and drag a box.
  • Circle — click the centre and drag out the radius.
  • N-Gon — free-form polygon: left-click to drop each vertex, then right-click to close the shape (needs at least three points).
Press Esc at any time to cancel a region you're in the middle of drawing.

5Detecting features

With an ROI in place, seed the points to track. Two strategies are available from the Detect toolbar group:

  • Corners (Shi-Tomasi) — finds strong, trackable corner features automatically.
  • Grid — lays down a regular grid of points, regardless of image content.

Fine-tune either method under Parameters → Corner Detection… and Grid…. Your settings are remembered between sessions.

6Tracking

Press Run Tracking (the primary blue button). ECM Tracker uses pyramidal Lucas-Kanade optical flow to follow every seeded point:

  • Forward from the reference frame to the last frame, then
  • Backward from the last frame back to the reference.

The round trip yields a forward–backward error for each point — the distance between where it started and where the return trip lands it. A small error means a reliable track; a large error flags a point worth dropping. Tune the optical-flow settings under Parameters → Tracker…

7Cleaning up tracks

Open Cleanup (in the Track toolbar group) to filter out unreliable tracks. As you adjust the sliders the canvas previews the result live:

  • Green — points that will be kept.
  • Red — points that will be dropped.

Cleanup is non-destructive: the original tracking result is never altered, points only ever leave the active set, and every filter step can be undone.

8Display options

Under the Display menu you can tailor the overlays:

  • Adjust feature-marker size and opacity.
  • Toggle Show ROI to hide or reveal the region outline.

Use the View toolbar group to zoom in, zoom out, or fit the image to the window. Drag with the middle or right mouse button to pan.

9Exporting

When you're happy with the surviving tracks, use the Export dropdown (toolbar or File → Export…, Ctrl+E):

  • NumPy array (.npy) — the tracked coordinates as an array, for downstream analysis.
  • CSV (.csv) — a spreadsheet-friendly table with interleaved x/y columns per frame.

10Plugins

ECM Tracker is extensible. The Plugins menu lists any installed add-ons for post-processing, custom export, or extra on-canvas visualisations. Several examples ship with the app — see the developer guide in the plugins/ folder to write your own.
